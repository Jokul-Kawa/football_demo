# 数据源、AI 与合规说明

## 1. 赛事数据

产品目标从世界杯单赛事升级为多赛事足球平台，数据源需要覆盖世界杯、欧冠、英超、西甲、德甲、意甲、法甲、中超等主流赛事。

当前代码仍包含 2026 世界杯 104 场占位赛程，用于验证接口、筛选、实时更新和移动端 UI。生产上线前必须替换为授权赛事数据源或由运营后台校对后的官方赛程。

数据流：

授权数据源或运营后台录入 -> 标准化 -> 业务存储 -> REST/SSE API -> Flutter App。

## 2. 视频直播

应用不自建视频直播，不抓取、不转封装、不盗链任何比赛视频流。

视频模块只展示官方持权平台入口，例如 CMG/CCTV/央视频或各联赛在中国大陆的官方转播合作平台。每个入口上线前需要运营确认版权边界、链接有效性和展示文案。

## 3. AI 预测与前瞻

AI 功能仅作为观赛内容参考，不作为投注、投资或其他决策建议。

必须遵守以下规则：

- 不展示赔率。
- 不引导用户投注。
- 不接入博彩平台。
- 每个预测页展示“仅供娱乐和观赛参考，不构成投注建议”。
- 高热比赛、争议内容和自动生成战报进入人工审核。
- 保留 AI 内容的生成时间、输入数据版本和审核状态。

## 4. 球星卡牌与抽卡

抽卡、集卡和合成玩法用于提升互动和留存，但首版不得引入现金交易。

限制：

- 不开放充值抽卡。
- 不开放卡牌交易。
- 不允许卡牌提现或兑换现金等价物。
- 不使用未授权球员肖像、官方赛事标识、俱乐部徽章或转播截图。
- 未成年人用户需要限制高频抽卡、强刺激文案和沉迷式任务。

素材策略：

- 优先使用自制插画、抽象球员卡面、授权图库或已获得授权的素材。
- 球员姓名、肖像、俱乐部标识和赛事标识上线前必须确认授权边界。

## 5. 品牌与素材

未获得书面授权前，不使用以下内容：

- FIFA、UEFA、英超、德甲等官方徽标、赛事徽标、吉祥物、奖杯图形。
- 未授权比赛图片、视频、转播画面截图。
- 暗示官方身份的 App 名称、描述、启动页或商店文案。

App 可以描述“提供世界杯、英超、德甲等赛事信息服务”，但不能自称“官方 App”或暗示与赛事主办方存在官方合作，除非已取得书面授权。
