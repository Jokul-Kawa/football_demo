# 数据源与合规说明

## 赛事数据

当前代码包含 104 场占位赛程，用于验证接口、筛选、实时更新和移动端 UI。生产上线前必须替换为授权赛事数据源或运营后台校对后的官方赛程。

数据模型按以下路径流转：

授权数据源或运营后台录入 -> 标准化 -> 业务存储 -> REST/SSE API -> Flutter App。

## 视频直播

应用不自建视频直播，不抓取、不转封装、不盗链任何比赛视频流。视频模块只展示官方持权平台入口，例如 CMG/CCTV/央视频等获得授权或公开可跳转的页面。

## 品牌与素材

未获得书面授权前，不使用以下内容：

- FIFA 官方徽标、赛事徽标、吉祥物、奖杯图形。
- 未授权比赛图片、视频、转播画面截图。
- 暗示官方身份的 App 名称、描述、启动页或商店文案。
